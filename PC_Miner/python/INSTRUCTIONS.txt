the settings file is miner_settings.json where all the wallet credentials are stored. this includes the wallet address and other sensetive data. the private
key would not be plainly stored in that file for security reasons and so it has to be encrypted. please use the show_key.py and run it in order to decrypt the data in miner_settings.json and reveal the private key, an example is shown below:

"python show_key.py miner_settings.json"

NOTE: be sure to save the show_key.py in the same folder as where the miner settings file is saved.

HOW TO SET UP THE MINER:
   NOTE: save requirements.txt in the same folder as the pc miner file
   to install all libs and modules, RUN: python -m pip install -r requirements.txt
   to activate the miner, RUN: python PC_Miner.py
   
   input ur password when prompted to, please note down this password as it would be important soon if u ever want to unencrypt the data in miner_settings.json    to get the private key.
